# 原创技术测试视频

front.mp4、back.mp4、mirror.mp4 由本项目使用 FFmpeg 的 color、drawgrid、drawtext、aevalsrc 合成。图形、通道标签、计时器和120 BPM合成节拍用于软件测试，不包含舞蹈、教师、第三方音乐或真实多机位拍摄。

每份24秒、640×360、15fps、H.264/AAC，统一时间轴起点0。画面标签的 FRONT / BACK / MIRROR 指测试通道；不代表真实舞蹈视角。对镜通道尤其不是真实对镜拍摄，也不是对另一段视频做 CSS 镜像。

项目作者将这三份原创合成视频按 CC0-1.0 提供，供本项目及其他软件测试复用。该声明仅覆盖合成视频，不改变代码或依赖的许可。

生成方法：使用纯色背景分别为 0x68493b、0x28483d、0x374660，叠加网格、英文技术标签和媒体时间；音频以660Hz、25ms的合成音每0.5秒提示一次。无额外下载素材。
