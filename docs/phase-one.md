# 第一阶段范围与验收

长期产品方向为《全民舞1.0综合舞蹈生态平台PRD》，当前交付限定为《V3.3手机横屏智能教学播放器方案》的第一阶段教学流程。继续迭代现有Next.js项目；使用 `feat/dance-player` 和 PR #1 审核，不直接修改main。

## 手机重点检查

- 在360px/390px竖屏选课，手动旋转到横屏；在667×320、844×390确认页面与沉浸模式不溢出。
- 加载明确标注的原创测试片，可一键开始/暂停、切换视角、循环本段；无需先进入系统全屏。
- 高级控件收起后数拍与动作提示仍可见，暂停只需一次点击；触控编辑时不突然收起。
- 视频contain完整呈现；状态文字、控件和水印不参与视频镜像。网页全屏不支持/拒绝时仍保留页内功能。
- 键盘进入沉浸后焦点保留在播放器内，Escape退出并回到入口；折叠内容不进入焦点循环。

## 验证记录

本轮 `npm run lint`、`npm run typecheck`、`npm run build` 全部通过；18项自动化测试全部通过，无失败或跳过，其中17项浏览器端到端测试、1项时间轴逻辑测试。新增覆盖依次导入三视角、沉浸进入/退出、常驻数拍和一键暂停、触控闲置计时、折叠内容焦点与667×320倍速控件首屏可见性。

Chromium自动化与模拟降级不代表iOS Safari、Android、微信真机验收。需要在授权教学素材接入后补充设备矩阵、多视角校准、字幕和弱网测试。

## 不属于本阶段

真实支付、正式AI动作评分、教师入驻市场、舞蹈社区、商城、复杂微服务。没有部署、购买付费资源或暗示已上线的真实后台。
