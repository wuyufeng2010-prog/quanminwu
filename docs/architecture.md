# V3.3 原型边界与下一步接入

## 当前数据流

静态课程数据 → App Router课程/目录页 → 客户端播放器 → 原生HTMLVideoElement。
视频 currentTime（减去视角偏移）→ 统一课程时间 → 分段、拍点和水印。
位置、设置、问题文本和文件名 → 当前浏览器localStorage；视频文件仅使用临时对象URL。

播放器没有跨域教学视频、网络上传或业务API调用。技术测试资源来自本项目同源静态目录。

## 统一时间轴

`VideoResource.timelineOffset`表示资源中的课程起点秒数：媒体时间 = 课程时间 + offset。
切换视角时记住课程时间和播放意图，等待新视频metadata后定位、恢复倍速，尽可能继续播放。浏览器拒绝自动恢复播放时提示用户再次点击。短素材会限制定位并停止超出时长的循环。

拍点模型使用课程时间的绝对时间戳，`offset`记录音乐起拍点（测试片为2秒，前2秒为5/6/7/8预备）。同步依据视频时间，不另起一条“假同步”动画或计时器。没有节拍自动检测；`reviewStatus: demo-only`不得当作教师审核结果发布。

正式视频应有字幕、专业动作提示和足够的动态热身/整理放松时间。当前测试片标签不构成舞蹈教学。

## 原型水印

水印由匿名演示编号、课程ID、DEMO会话ID组成，媒体时间每5秒在边缘换位。整容器全屏可保留覆盖层，原生视频全屏不能可靠保留，所以不自动调用原生全屏。暂停时水印停止换位，以减少干扰。

不是DRM、烧录或不可移除安全水印。没有后台账号映射，不能追溯真实学员。浏览器截图、样式修改和录屏无法被此原型阻止。

## 接入接口（尚未实现）

- `PlaybackAuthorizationProvider.authorize(courseId)`：服务端鉴权后返回短期有效资源和服务器水印会话。密钥保存在服务端，客户端不能授予自己课程权益。
- `BeatAnalysisProvider.analyze(audio)`：未来分析结果进入教师审核流程，只有已审核的拍点与动作时间轴用于正式课程。
- Supabase或其他数据库：通过服务器适配层绑定真实用户、课程授权、进度和问答，建立访问控制与删除策略；不把service-role密钥放到浏览器。
- 私有练习视频：验证文件、大小、课程与用户权限后签发短期上传许可；教师端按权限获取短期读取地址，提供删除和保留策略。当前本地文件名不等于上传成功。
- 教师反馈：增加异步消息状态、文字/语音/视频反馈及审核。原型里的固定示例不属于真实教师回复。

## 验证范围

Playwright使用实际Chromium媒体播放测试（H.264/AAC），覆盖播放/暂停/拖动/倍速、三通道切换、缺失素材、本地损坏文件、AB边界与回跳、音乐时间同步、本地恢复、示例答疑、不上传文件、响应式与全屏降级。

自动化尺寸与触控模拟不等同于 iOS Safari、Android 或微信真机验收。正式上线前需至少补充字幕、移动设备自动播放策略、方向锁定、全屏安全区域、弱网、媒体时长差异与不同编码的设备矩阵。
